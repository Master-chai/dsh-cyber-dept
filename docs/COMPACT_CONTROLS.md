# 任务看板与员工介绍展示调整

本补丁基于已有执行与待处理动作集成修复，只调整以下展示，不推送、不安装、不修改实际任务。

## 最终要求

- 五个状态筛选按钮（全部、进行中、待办、受阻、已完成）：按截图中的 44px 高度减少约 1/3，设为 30px。
- 任务详情“立即执行”“删除任务”：按截图中的 44px 高度减半，设为 22px。
- 员工介绍移除“成员 ID”展示行。内部成员 ID、头像身份、任务关联和原生会话导航照常使用。
- 页面不再挂载“需要你处理”区域。仍保留任务详情依赖说明、操作确认、错误回执及员工介绍中的原生审批入口；没有关闭审批或改动任务执行、依赖校验。

## 尺寸与触屏

原样式把状态筛选、任务操作、进度和分页合并设置桌面 22px，但 `any-pointer:coarse` 会将可见按钮恢复为 44px。此媒体条件也可能出现在带触屏的桌面电脑。照片本身不能证明用户机器命中了哪条媒体查询，也不能证明宿主是否另有样式覆盖。

本次将筛选与任务操作独立设置明确高度、逻辑块高度、16px 行高和 flex 居中；不缩放文字，不更改进度按钮、分页按钮、对话框或任务行尺寸。原有悬停、选中、危险色、禁用和键盘焦点样式保留。

触屏与混合设备的可见高度同样为 30px / 22px。透明伪元素将点击区域垂直扩展至 44px，宽度至少44px；多行筛选与操作的行间距分别为18px和24px，避免相邻行的点击区相互覆盖。这个命中区计算和选择器已做源码回归，真实浏览器的点击与布局仍需下述实机验证。

1. 完整重启 DSH，确认五个筛选按钮约30px、两项详情操作约22px，文字居中，既有浅深色风格不变。
2. 在鼠标、触屏或混合设备，检查筛选换行、搜索框、按钮边缘点击及键盘Tab焦点，确认没有相邻点击区重叠。

4. “需要你处理”区域不再显示；依赖阻塞提示、立即执行/删除确认、未知结果提示仍按原逻辑工作。
