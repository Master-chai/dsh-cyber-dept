# 员工操作区与办公室悬停提示

本次界面修改基于已合并 PR #5 的 main `a0b6bf722d73dd437be663122aeb31bc105a5a79`。

## 修改范围

- 员工介绍下方不再显示“沟通”标题和“可沟通 / 只读”徽标。操作区保留无障碍名称、可写状态属性、只读原因和操作回执。
- 只缩小该区四个操作按钮：面板不超过 700px 时从 44px 改为 22px，较宽面板从 32px 改为 16px。文字不缩放，保留原颜色、边框、圆角、禁用态和焦点轮廓。
- 操作区自身可用宽度至少 360px 时四列，否则两列。第三个按钮仍按任务状态显示“完成任务”或“重开任务”。审批入口继续独占整行，保留原高度；确认弹窗不缩小。
- 鼠标可点击范围至少 24px 高；粗指针设备通过透明范围保留 44px 高。上下留白和行距随点击范围变化，避免相邻按钮互相覆盖。
- 办公室不再通过画布上的鼠标移动或工牌的鼠标移入显示状态浮层。鼠标点击仍选择成员，键盘可见焦点保留状态说明；Escape、失焦及点击仍关闭说明。工牌文字、状态判定、动画和办公室模块保留。

## 验证

- `npm run build` 和 `npm test` 通过，包括产物一致性、ESLint、TypeScript 及 370 项 Node 测试，0 失败、0 跳过。`git diff --check` 通过。
- 新增或更新回归覆盖标题栏移除、只读提示、16/22px 高度及 24/44px 点击范围间距、四种操作反复打开/取消、重开任务、离线/审批/只读状态、鼠标不触发浮层、键盘焦点与 Escape/失焦关闭、画布和工牌点击选择。
- 全量回归仍覆盖两辆自行车的缩放与偏移点击、休闲活动、任务写入确认和动画生命周期。
