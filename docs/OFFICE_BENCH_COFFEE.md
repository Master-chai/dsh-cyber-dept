# 卧推与咖啡制作

办公室继续使用原有灰度像素画法、两台骑行台和原有员工/任务数据。新增两台独立卧推架，场景底部留出健身区，所有卡座到器械和咖啡机之间均有可走通的路径。

## 动作与占用

- 卧推：走到器械、坐下、躺下、握杠、出架，完成四次约 4.4 秒的动作，随后回架、松手、起身。每次为 2 秒下放、0.35 秒停顿、1.5 秒推起与 0.55 秒顶端稳定。
- 手腕使用杠铃的同一坐标解，肘部采用两段固定长度骨架。动作中肩背和臀部贴凳，双脚保持地面接触；杠铃沿胸部到肩部上方的小幅斜线运动。
- 咖啡：走到唯一咖啡机前、准备杯子、按键、出液入杯、取杯、饮用、放回杯子。出液仅发生在杯子仍位于托盘时。
- 两台卧推、两台单车和一台咖啡机分别预约，满员时选其他休息活动，不抢占、不叠放。
- 实际工作、待审批或异常会打断休息。卧推先受控回架再起身，咖啡立即停止出液并放回杯子，再连续走回工位。离开器械范围后释放预约，成员移除和场景销毁也释放占用。
- 休息动画不修改任务、会话或完成状态。离线且有未完成任务的成员仍只在工位待机。原始 running 和无工具名称的待审批事实仍优先禁止休息。

## 性能与暂停

- 复用原来的单 RAF，常规绘制上限约 30fps，无新增计时器或独立动画循环。
- 房间、工位和台架主体继续预绘到缓存画布；空闲卧推杠铃也使用全场共享的 145×106 离屏小画布缓存（约 62KB 原始像素），不逐帧重画台架或像素线段。像素线段采用标量插值，避免每像素创建临时点对象。
- 寻路仅在出发/返回时执行，不在重复动作帧里执行。
- 隐藏、离屏、收起、不活跃及系统减少动态效果会停止调度；暂停时间不计入动作。减少动态时采用确定的静止姿势。
- 新增动作有额外绘制工作，不能保证零成本。微基准与真实浏览器预览只能说明其测试环境，不能代替 DSH 宿主设备上的帧率验收。
