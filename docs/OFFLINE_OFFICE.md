# 离线办公室与按钮排列

本次更新基于 main `a561d4d03a783a7ca2c894cd9136d7af85cb8406`，保留已有像素人物、卡座、两辆骑行台、黑白配色与 UI 控件风格。

## 行为

- 原来离线状态会立即清空路径、释放自行车并把人物放回工位，帧调度也排除了离线成员。现在连接状态与办公室动作独立，离线不会把人物冻结或瞬移。
- 空闲、已完成以及尚无任务完成证据的离线成员轮换咖啡、骑行、散步、工位看手机。所有动作均为模拟，不会产生宿主指令或修改任务。
- 只有原生任务板中确有已完成归属任务，且所有其他归属任务都已完成、无未完成任务引用、归属身份明确，才展示完成徽标与“任务完成 · 离线休息”。`turn/end`、历史完成计数或离线本身均不是完成证据。
- 离线且仍有待办/进行中任务时，只允许工位手机待机，不展示完成标记。真实执行、审批、错误或准备状态会中断休闲并连续走回工位。
- 会话摘要、原生运行状态、成员运行状态任意一方报告正在执行，都能否决休闲；一方的 false 不会覆盖另一方的 true。此判断独立于现有离线显示优先级。
- 双车保留独立占用；人物走离自己的垫子后才释放该辆车。暂停/恢复不丢占用。被移除成员、卸载引擎仍释放占用。
- 折叠、隐藏页面、离屏、非活动面板和系统减少动态效果仍停止动画循环。恢复不补跑隐藏期间的时间，每个办公室仅保留一个动画循环。
- 员工沟通区按自身可用宽度排列：至少 360px 时四个按钮一排，更窄时两列两排。保留原按钮高度、配色、标签、确认弹窗；审批入口独立整行。
