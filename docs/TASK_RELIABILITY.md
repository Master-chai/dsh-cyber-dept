# 待处理事项与操作回执

“需要你处理”显示当前快照中能核实的审批、成员错误、未指派任务、缺失负责人、离线/初始化成员、未完成依赖，以及本页失败或结果未知的操作。没有上述待处理事项时整个面板隐藏，有事项时自动显示。普通成功/发送中回执不会单独触发显示；失败、部分成功或送达未知的回执仍保留。它是只读导航：审批仍需在 DSH 原生会话处理，任何派活、执行、删除或重发仍走原有确认和去重流程。不会自动重试，不会根据等待时长判断任务卡死。

任务详情分开呈现任务看板状态、负责人当前活动、可核实阻碍与下一步。“进行中”是 DSH 看板状态，指派即可进入；成员正在思考或调用工具并不能证明在执行这项任务。当前接口没有任务级开始执行、已读、完成验收的独立事件，因此 UI 明确显示未确认，而不生成虚假阶段。

操作回执在当前浏览器页面生命周期内保存最近 64 条普通或已核对操作；尚未结束的请求与未核对异常合计最多256条，不被成功记录淘汰。满额后新的请求不会发送，需先在原生会话核对，再二次确认“已核对，移出提醒”。此操作仅标记本地提醒，不改变宿主状态。关闭对话框不删除回执，刷新整个页面后清除。回执按楼层隔离，保留宿主返回的操作编号及消息编号，不保存发送消息正文。发送成功只说明宿主调用返回成功，不证明成员已经读到或开始执行。

超时、断线、未知结果都不能当作失败重发。先打开成员会话并核对任务归属、状态和操作编号；本页不会自动重新发送。已有部分成功（创建/指派成功但后续通知失败）会保留原任务，并显示对应下一步。

验证：基于模拟宿主与 React 组件测试；未向真实 DSH 成员发送消息或执行写操作。真实宿主端到端送达与执行仍需在已授权的 DSH 实例验证。
