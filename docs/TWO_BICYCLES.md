# 双骑行台实现与验证

办公室左侧休息区现在有两台骑行台，可同时供两位空闲或已完成工作的 Agent 模拟骑行。休息动作不修改真实 DSH 任务状态，也不代表真实疲劳。

## 实现

- 两台坐标为 `(88, 392)`、`(88, 504)`，各自保存独立 `id` 和 `owner`；人物保存当前 `bikeId`。
- 沿原休息区上下排列，不侵入工位。小团队办公室最小高度由 448 增至 560；完整 12 人办公室仍为 640 × 648。
- 出发前预约，只有路径可达才取得该车。两台均被预约时，下一位成员去咖啡区，不抢占已有位置。
- 新工作或审批会让休息者沿路径返岗；离开自己的车足够远后只释放该车。离线、成员移除、引擎销毁也会清理预约。
- 保留既有物理踩踏动画、30 fps 上限、一个 RAF 循环和背景缓存。不加载新素材或网络资源。
- 减少动态效果或暂停时不新建休息行程，已有动作与预约保持；恢复时继续且不补算隐藏时间。

## 自动验证

执行 `npm run build` 和 `npm test`，构建一致性、ESLint、TypeScript 与全部 **330 项测试通过**。

新增或扩展覆盖：

- 1、2、3、6、9、12 个工位往返两台车，无家具或另一台车占地穿越。
- 12 人连续模拟 480 秒，实际出现双人同时骑行，预约无重复。
- 12 人混合工作、审批、离线与恢复模拟 480 秒，没有遗留占位。
- 第三人无车可用、途中工作召回、两台分别离线及销毁释放。
- 出发、骑行、返岗各阶段的 inactive、reduced-motion、隐藏、离屏暂停与恢复。
- 真实 React OfficeScene 与引擎运行后，分别点击两位骑行者；0.5×、1×、1.5× 缩放，正/负画布偏移与头部/身体目标共 36 次均选中正确成员。
- 浅色/深色、2/9/12 人的背景绘制快照与原有骑行动作测试。

## 预览与限制

浅/深色 PNG 由实际场景绘制代码生成，双人同时骑行画面来自状态机自然模拟到 67.28 秒，并非手工把两人放上车。另有独立离线 HTML 预览，可切换主题、播放/暂停、点击成员和模拟返岗。

本地 Node Canvas 性能抽查：12 人、1000 帧，单车版本平均约 2.37 ms/帧，双车版本约 5.15 ms/帧。生成客户端增加 543 字节。这仅是本地渲染抽查，不是浏览器或真实 DSH 性能承诺。

当前执行环境阻止 Chromium 创建所需 socket，额外浏览器截图测试未能启动。真实 DSH 内的加载、宽窄窗口观感和动画流畅度仍需宿主验收；没有部署或推送。
