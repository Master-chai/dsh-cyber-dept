# 黑白界面与可靠性整合版

基于 main `1d3461a2381037fe9e93c9a2424af58273878c8f`，仅本地实现，未推送、发布或安装到真实 DSH。

## 视觉改动

- 移除插件对 `--dsw-alias-*` 宿主变量的覆盖，改为单向读取宿主 token；独立预览使用中性浅深 fallback。
- 办公室房间、桌面、人物与提示全部灰阶。非办公室的错误/审批语义色仍遵循 DSH，以免隐藏重要警示。
- 人物在工位时面向屏幕，行走时仍按路径朝向。保留 lively、30fps、空闲休息、状态动作、离屏暂停及系统 reduced-motion。
- 六位原创虚构员工肖像本地内嵌，成员 ID 确定稳定头像；卡片突出姓名、角色、职责、当前任务，保留模型、工具、错误、审批信息与原有沟通确认流程。

## 新增功能

- “需要你处理”：基于已知审批、阻塞、错误及本页回执，提供原因和下一步，不按等待时长推断卡死。
- 本页回执：区别宿主接收、失败、送达未知。宿主接收不代表成员已读或开始工作，不会自动重试。
- 任务依赖与范围说明：沿用宿主快照，不自行改变执行状态。
- 本地预算与员工档案：仅本地手动规划。真实 token/费用不可用，不会阻止任务执行，也不会改变宿主模型配置。档案支持 JSON 文本导入导出、明确确认删除。

## 验证

1. 原始 main 基线：`npm test` 249/249。
2. 最终整合：`npm run build` 成功；`npm test` 272/272，包含产物一致性、ESLint、TypeScript 和全部 Node 测试。
3. 新增视觉测试覆盖主题变量无覆盖/环依赖、全灰阶、桌前朝向/行走朝向、原动画策略和本地肖像身份映射。
4. 肖像 PNG 无损转换 WebP，并核对解码 RGB 像素完全一致。最终 client.js 约 2.22 MB，无运行期图片网络请求。
5. 实际员工卡片和任务看板可由 React SSR 生成静态 HTML 供查看；这不是浏览器验收或真实 DSH 验收。

## 运行

按原 README 安装要求，在独立副本执行 `npm ci`、`npm run build`、`npm test`，再按本地链接方式加入 DSH。不要直接覆盖正在运行的插件目录；保留原版以便回退。

本地规划边界已补回归：最大合法 JSON 转义字段、旧超 150k 数据恢复、损坏/超限数据明确确认清空与并发保护；导出和导入支持同一字段上界。
