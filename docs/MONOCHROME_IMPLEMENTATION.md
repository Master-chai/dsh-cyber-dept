# 当前界面修订与验证边界

基于 main `7827c9057a6875f604f74dd35e682b659ff2f885`。

## 当前改动

- 保持 DSH 主题变量单向读取，不覆盖宿主 token。模块标题去除灰色底条与可见边框，保留尺寸、折叠与键盘焦点。
- 任务看板最上，员工介绍和团队成员居中，办公室位于最后。任务 ID 位于标题右侧，桌面任务行最小32px；长标题最多两行，状态独立列。触控设备最小44px。
- 原创本地像素头像，每格512×512，按成员 ID 稳定映射。没有运行期头像网络请求。
- 办公室工位、桌面、人物与提示保持灰阶；工位人物面向电脑，独立椅背正确遮挡。保留30fps、离屏暂停与系统减少动态效果。
- 新增单人骑行台。空闲或完成后可模拟咖啡/骑行休息，接到工作连续归座，离线释放占位。这不是模型真实疲劳，不修改宿主工作状态。
- “需要你处理”无事项隐藏，有已知问题出现时显示。未知或异常回执不会被普通成功记录挤掉；移出提醒需明确确认，绝不代表宿主操作成功。

## 已取消的模块

“消耗与预算”和“可复用员工档案”及其清空入口、读写代码均已移除。此前浏览器本地记录不读取、不清除、不迁移、不覆盖。

真正的任务 Token 和费用统计尚未接入，没有占位统计界面。仓库中的严格绑定和定价纯函数仅是未接线的准备代码，不代表已实现整任务计费或已扣款核验。

## 验证

`npm run build` 与 `npm test` 已通过；当前294项测试包括产物一致性、ESLint、TypeScript及Node回归。骑行测试覆盖占位、归座和冻结；任务/头像/提醒及已取消模块均有回归覆盖。

静态HTML使用实际React组件与示例数据；独立PNG按组件结构绘制，办公室来源于场景源码。它们不是浏览器截图或真实DSH运行验收。

尚未验证真实DSH写操作、安装版本的Team接口兼容、宿主主题覆盖及实体窄屏/触控体验。当前官方宿主API存在代际变化，部署前需确认实际DSH版本。README旧截图保留为历史参考。

## 本地验证

在独立副本执行 `npm ci`、`npm run build`、`npm test`，再按README流程安装到测试用DSH。保留原版便于回退。本修订不自动部署、不合并主分支。
